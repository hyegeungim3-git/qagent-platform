# GenOS v4 로드맵 — "데모"에서 "파일럿"으로

> v3(P1~P5 완료, 2026-07-12)까지: 살아있는 데모(라이브 엔진·알림), 플랫폼성 증명(팩 스튜디오·시나리오 빌더), 규제 서사 실동작(XAI·감사 추적), 설치형 앱(PWA·접근성 100). 전 콘텐츠는 mock 시뮬레이션.
> **v4의 방향: mock의 껍질을 한 겹씩 실물로 바꿔, 발주처가 "이건 데모가 아니라 파일럿"이라고 느끼게 만든다.** 실행 규칙은 V3-ROADMAP과 동일(genos-work 루프, DoD 실행 증거, 코어-팩 불가침).

## W1. 실 LLM 연동 모드 (하이브리드) — 최우선 추천

**무엇**: 관리자 'LLM 관리'에 실 엔드포인트 설정(OpenAI 호환 URL·모델명·키는 localStorage — 저장소 커밋 금지)을 추가하고, 사용자 포털 GENERAL에 **모드 스위치: 시연(mock) / 실연동(live)**. 실연동 시 sampleAnswers 미적중 질의를 실 LLM에 전달하되, 시스템 프롬프트에 도메인 팩 컨텍스트(조직·용어·근거 문서 발췌)를 주입해 도메인 톤을 유지. 실패·타임아웃 시 mock 폴백(데모 무중단).
**왜**: "실제로 물어봐도 되나요?"는 모든 시연의 마지막 질문이다. 하이브리드라 데모 안정성은 유지된다.
**DoD**: ①mock 모드 기존 회귀 전체 통과 ②실연동 모드에서 임의 질문 → 실 응답 + XAI 푸터(신뢰도 미산출·모델 지식 표기) ③엔드포인트 미설정/오류 시 mock 폴백 + 안내 ④키가 커밋·번들에 미포함(스캔 증거).

## W2. 멀티 사용자 시연 — 결재가 왕복하는 데모

**무엇**: 포털에서 페르소나 선택(담당자/팀장/처장 — 팩 결재선 재사용). 담당자가 시나리오 완주로 만든 문서가 팀장 페르소나의 '결재함'에 도착 → 승인/반려(사유) → 담당자 알림 센터로 회신. localStorage 공유로 탭 2개 병렬 시연 가능(storage 이벤트 동기화).
**왜**: HITL이 배지에서 실제 업무 흐름이 된다. "사람 확인 지점"의 완성형.
**DoD**: ①담당자 완주→팀장 결재함 1건 도착 ②반려 사유가 담당자 알림+감사 추적에 기록 ③탭 2개 동시 열고 실시간 반영(storage 이벤트) ④SECURE 산출물은 결재함 미전송.

## W3. 진짜 다국어 — 해외 발주처 데모

**무엇**: v3 P5의 'UI 크롬 영어 토글'을 콘텐츠까지 확장 — 팩 스키마에 선택적 `en` 병기(suggestions·sampleAnswers·시나리오 제목), 영어 전용 데모 팩 1종(예: 글로벌 제조 법인) 신설. 언어 전환 시 콘텐츠가 있으면 영어, 없으면 한국어 폴백.
**DoD**: ①영어 팩에서 제안 카드→답변→시나리오 완주 전 과정 영어 ②기존 3팩 한국어 회귀 무손상 ③언어 전환이 새로고침 없이 반영.

## W4. 다크모드 1급 승격

**무엇**: v3의 CSS 스킨(유틸 오버라이드)을 디자인 토큰 체계로 재설계 — th 토큰을 3상태(light/dark/secure)로 확장하고 에이전트 13종·관리자까지 적용, 스킨 CSS 제거.
**왜**: 야간 관제·상황실 데모 대비. 스킨 방식은 파스텔 배지·차트 대비의 한계가 있다.
**DoD**: ①verify.mjs 라이트/다크 × 3도메인 확장 통과 ②에이전트 13종 다크에서 가로 스크롤·대비 문제 0 ③Lighthouse 접근성 다크에서도 90+.

## W5. 운영 완성도 — 데이터 수명주기

**무엇**: localStorage 전 키(convos·feedback·audit·customPack·customScenarios·uiPrefs) 통합 관리 — 관리자 '데이터 관리'에 현황·내보내기(JSON 백업)·가져오기·전체 초기화. 시연 전 "깨끗한 상태로 리셋" 원클릭.
**DoD**: ①백업 내보내기→초기화→가져오기 왕복 후 상태 동일 ②시연 리셋 원클릭 후 verify.mjs PASS ③키 목록이 문서와 일치(누락 스캔).

## 우선순위 근거

W1이 첫 번째: 파일럿 전환의 본질이고, W2·W3의 가치도 실 LLM 위에서 배가된다. W2는 공공기관 결재 문화에 직결되는 차별화. W3은 해외 영업 시점에, W4는 관제 데모 확정 시점에 착수. W5는 시연이 잦아지는 순간 필수가 된다.
